IPMe — Privacy Policy

Last updated: October 26, 2026

IPMe does not collect, store, or transmit any personal data. Your privacy is fully protected.

What data does IPMe collect?

None. IPMe does not collect any personal information, usage data, analytics, or telemetry.

Network requests

IPMe makes the following network requests to function:

  • IP geolocation lookup — Your public IP address is sent to a third-party geolocation API (freeipapi.com, with ipapi.co as a fallback) to determine your approximate location, ISP, and related network information. These services have their own privacy policies.
  • DNS Leak Test (Pro feature) — A DNS query is made to a test service to determine which DNS resolver is handling your requests. This is used solely to check for DNS leaks.
  • VPN range list — About once a week, IPMe downloads a public list of IP ranges published by VPN providers from GitHub. Your public IP is compared against this list on your Mac to detect a VPN running on your router or network. Your IP address is not sent anywhere as part of this check.
  • Network Pulse (Pro feature) — TCP connections are made to public DNS servers (Cloudflare 1.1.1.1 or Google 8.8.8.8) to measure network latency. No data is transmitted beyond the connection itself.

All network requests are made directly from your device. IPMe has no backend server, proxy, or intermediary.

Data storage

All app data (settings, IP history, logs) is stored locally on your Mac within the app's sandboxed container. Nothing is uploaded, synced, or shared.

Third-party services

  • Apple StoreKit — Used to process In-App Purchases. Purchase transactions are handled entirely by Apple. IPMe does not operate any payment server.
  • GitHub — Hosts the VPN range list. The download is a plain file request; like any web server, GitHub sees the requesting IP address.
  • freeipapi.com / ipapi.co — Used for IP geolocation lookups. Your public IP address is visible to these services as part of the lookup request (as it would be to any website you visit).

Accounts and authentication

IPMe does not require or support user accounts, sign-ups, or logins.

Children's privacy

IPMe does not collect data from anyone, including children. The app contains no objectionable content and is rated 4+.

Changes to this policy

If this policy is updated, the changes will be posted on this page with a revised date. Since IPMe collects no data, material changes are unlikely.
